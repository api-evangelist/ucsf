# UCSF API Examples

Every file in this directory is a **live response captured from a UCSF-operated endpoint** on
2026-08-19, not a hand-written illustration. Each carries a `_provenance` block naming the exact
request URL, the HTTP status, and any trimming applied for readability.

| File | Surface | Operator |
|---|---|---|
| `ucsf-profiles-json-api-response.json` | UCSF Profiles JSON API (`api.profiles.ucsf.edu`) | institution |
| `ucsf-industry-documents-single-document.json` | UCSF Industry Documents Library Solr API (`solr.idl.ucsf.edu`) | institution |
| `ucsf-industry-documents-search-response.json` | UCSF Industry Documents Library Solr API (`solr.idl.ucsf.edu`) | institution |
